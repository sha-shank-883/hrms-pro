# HRMS Mobile Communication Module

## What This Is

An enterprise-grade, mobile-first communication module for the existing HRMS mobile app. Inspired by Slack and Microsoft Teams, it provides robust real-time messaging, group channels, and file sharing directly within the HR platform to enhance employee collaboration.

## Core Value

Frictionless, real-time collaboration that connects employees instantly without leaving the HRMS ecosystem.

## Requirements

### Validated

- ✓ Core HRMS structure (Departments, Employees) — existing
- ✓ Basic authentication and multi-tenancy — existing
- ✓ WebSocket foundation (Socket.IO) — existing

### Active

- [ ] Real-time 1-on-1 messaging
- [ ] Group chats and Employee channels (both auto-generated by org structure and user-created)
- [ ] File sharing capabilities within chats
- [ ] Typing indicators to show active presence
- [ ] Read receipts for message tracking
- [ ] Message reactions (emojis)
- [ ] Push notifications for mobile alerts
- [ ] Scalable socket architecture handling concurrent connections
- [ ] Mobile-first UX tailored for the existing React Native app

### Out of Scope

- [ ] Video/Audio calling — Focus is on text/file-based communication for v1 to ensure stability.

## Context

- The project is a brownfield addition to a well-established Node.js/Express backend and React Native (Expo) mobile frontend.
- A basic Chat module exists for the web frontend using Socket.IO, but this needs to be vastly upgraded to "enterprise-grade" and adapted for a mobile-first experience.
- The new module must respect the existing multi-tenant architecture and authentication (JWT).

## Constraints

- **Tech Stack**: Must use the existing stack (Node.js, PostgreSQL, Socket.IO, React Native/Expo).
- **Performance**: The socket architecture must be scalable to handle real-time events across potentially large organizations.
- **Mobile Environment**: Must perform well within the constraints of React Native (e.g., efficient list rendering for chat histories).
